# Caso compra de notebook com vício

Repositório didático para demonstrar organização, sanitização, RAG manual, verificação, auditoria e revisão humana. Todos os nomes, contatos, números, datas do caso e documentos são inventados.

## Fluxo

1. Leia `docs/limites_e_sigilo.md` e `docs/especificacao.md`.
2. Compare `entrada/relato_bruto.md` com `apoio/caso-sanitizado.md`; não use identificadores na consulta.
3. Siga `docs/prompts/consulta_rag.md` usando somente as fontes de `apoio/`.
4. Confira resposta, verificação, auditoria e revisão humana em `evidencias/`.
5. Consulte `entrega/orientacao_inicial.md` como exemplo acadêmico, não como aconselhamento para caso real.

## Critérios

- Cenário coerente, explicitamente fictício; dados identificados e minimizados.
- Duas fontes públicas com URL, artigo e trecho localizados.
- Prompt limitado às fontes e com lacunas declaradas.
- Verificação, auditoria e revisão humana rastreáveis.
- Finalidade, público, limites, critérios, orientação e URL pública real documentados.
